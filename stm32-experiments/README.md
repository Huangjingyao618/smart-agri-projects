# STM32 嵌入式实验集合

8个 STM32F103C8T6 基础实验，体现嵌入式外设驱动开发能力。

| # | 实验名称 | 涉及外设/知识点 |
|---|----------|----------------|
| 1 | 3-2 LED流水灯 | GPIO输出、延时 |
| 2 | 3-4 按键控制LED | GPIO输入、消抖 |
| 3 | 3-5 光敏传感器控制蜂鸣器 | ADC、光敏传感器 |
| 4 | 4-1 OLED显示屏 | I2C、OLED驱动、中文显示 |
| 5 | 6-4 PWM驱动舵机 | 定时器PWM、舵机控制 |
| 6 | 8-2 DMA+AD多通道 | DMA、ADC多通道采集 |
| 7 | 9-2 串口发送+接收 | USART、中断收发 |
| 8 | AD多通道 | ADC多通道、数据采集 |

## 技术栈
- MCU: STM32F103C8T6
- IDE: Keil MDK
- 库: STM32标准外设库
- 语言: C
