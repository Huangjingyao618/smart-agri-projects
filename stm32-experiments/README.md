# 🔬 STM32 嵌入式外设实验集

> 8 个 STM32F103C8T6 基础实验，系统覆盖嵌入式开发核心外设，体现驱动开发与硬件调试能力。

---

## 📋 项目简介

本实验集涵盖了 STM32F103C8T6 最常用的外设驱动开发，从 GPIO 输入输出的基础实验，到 ADC 多通道 DMA 采集、PWM 舵机控制、串口通信等进阶内容。每个实验均包含完整的 Keil 工程文件（User / Hardware / System 三层架构），可直接编译烧录运行。

---

## 📊 实验列表

| # | 实验名称 | 涉及外设 | 核心知识点 | 难度 |
|---|----------|----------|-----------|------|
| 1 | **3-2 LED 流水灯** | GPIO | GPIO 推挽输出、延时函数、位操作 | ⭐ |
| 2 | **3-4 按键控制 LED** | GPIO | GPIO 上拉输入、按键消抖、状态机 | ⭐ |
| 3 | **3-5 光敏传感器控制蜂鸣器** | ADC + GPIO | ADC 单通道采集、模拟传感器、阈值判断 | ⭐⭐ |
| 4 | **4-1 OLED 显示屏** | I2C | I2C 总线协议、SSD1306 驱动、中文/图形显示 | ⭐⭐ |
| 5 | **6-4 PWM 驱动舵机** | 定时器 (TIM) | PWM 输出、占空比控制、舵机角度映射 | ⭐⭐ |
| 6 | **8-2 DMA+AD 多通道** | ADC + DMA | ADC 多通道扫描、DMA 自动搬运、数据缓冲 | ⭐⭐⭐ |
| 7 | **9-2 串口发送+接收** | USART | 串口通信协议、中断接收、数据回显 | ⭐⭐ |
| 8 | **AD 多通道** | ADC | 多通道 ADC 轮询采集、数据滤波 | ⭐⭐ |

## 📁 项目结构

每个实验目录统一采用三层架构：

```
3-2 LED流水灯/
├── User/               # 用户层：main.c + 中断服务
├── Hardware/           # 硬件抽象层：外设驱动
└── System/             # 系统层：延时/时钟配置
```

## 🛠️ 技术栈

| 类别 | 技术 |
|------|------|
| **MCU** | STM32F103C8T6 (ARM Cortex-M3, 72MHz, 64KB Flash, 20KB SRAM) |
| **IDE** | Keil MDK v5 |
| **库** | STM32 标准外设库 (StdPeriph Library) |
| **调试** | ST-Link v2 调试器 + 串口助手 |
| **语言** | C |

## 🎯 学习目标

通过这 8 个实验，掌握了以下嵌入式开发核心能力：

- **GPIO 编程** — 输入输出的各种模式 (推挽/开漏/上拉/下拉)
- **中断系统** — 外部中断、串口中断的配置与使用
- **定时器应用** — 通用定时器的 PWM 输出与占空比调节
- **ADC 数据采集** — 单通道/多通道、轮询/DMA 传输模式
- **通信协议** — I2C (OLED 驱动)、USART (串口收发)
- **传感器驱动** — 光敏传感器、DHT11 等农业常用传感器
- **模块化设计** — User/Hardware/System 三层代码分离架构
