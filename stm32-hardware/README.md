# 🔧 STM32 硬件端 — IoT 远程监控系统

> 基于 STM32F103C8T6 的物联网终端：传感器采集 → MQTT 上报 → 远程控制

---

## 📋 项目简介

本项目是智慧农业 IoT 全链路系统的硬件终端，负责**数据采集**与**命令执行**。通过 DHT11 传感器采集环境温湿度，经 ESP8266 WiFi 模块通过 MQTT 协议上报至 OneNET 云平台，同时接收来自微信小程序的远程 LED 控制命令，并在 OLED 屏幕上本地显示实时数据。

## 📁 项目结构

```
stm32-hardware/
├── User/
│   ├── main.c              # 主程序: 传感器采集 → 显示 → 上报主循环
│   ├── esp8266.c / .h      # WiFi AT 命令 + MQTT 协议栈 (CONNECT/SUBSCRIBE/PUBLISH/PINGREQ)
│   ├── DHT11.c / .h        # DHT11 单总线温湿度传感器驱动
│   └── stm32f10x_it.c      # 中断服务 (SysTick/USART)
├── Hardware/               # 外设驱动
│   ├── LED.c / .h          # LED 控制
│   ├── OLED.c / .h         # 0.96寸 OLED (I2C) 驱动 + 中文显示
│   ├── Buzzer.c / .h       # 蜂鸣器驱动
│   └── Key.c / .h          # 按键驱动 (含消抖)
└── System/                 # 系统层
    └── delay.c / .h        # 微秒/毫秒延时函数
```

## 🛠️ 技术栈

| 类别 | 技术 |
|------|------|
| **MCU** | STM32F103C8T6 (ARM Cortex-M3, 72MHz) |
| **IDE** | Keil MDK v5 |
| **库** | STM32 标准外设库 (StdPeriph) |
| **传感器** | DHT11 数字温湿度传感器 |
| **通信** | ESP8266 WiFi 模块 (AT 命令 + TCP 透传) |
| **显示** | 0.96 寸 OLED (I2C, SSD1306 驱动) |
| **协议** | MQTT v3.1.1 (手写报文构造，非第三方库) |
| **语言** | C |

---

## ✅ 功能清单

- ✅ DHT11 温湿度数据实时采集 (1秒/次)
- ✅ 数据定时上报至 OneNET 云平台 (10秒/次)
- ✅ 远程 LED 控制 (小程序下发 → MQTT → 硬件执行)
- ✅ OLED 本地显示 (温湿度 + 上报次数计数)
- ✅ 按键本地控制 LED 开关
- ✅ WiFi 断线自动重连 (3次重试机制)
- ✅ MQTT 双模式自适应：AT 命令模式 / TCP 透传 + 手动 MQTT 报文
- ✅ 弱网可靠性保障：指令下发 → 云端确认 → 硬件执行 三段式机制
- ✅ MQTT 心跳保活 (PINGREQ 定时发送)

## 🚀 使用说明

1. 使用 Keil MDK 打开工程
2. 在 `User/esp8266.c` 中修改：
   - WiFi SSID / 密码
   - OneNET 产品 ID / 设备名称 / MQTT Token
3. 编译 (Build) → 烧录 (Download) 至 STM32F103C8T6
4. 按复位键启动，观察 OLED 显示连接状态
5. 配合 [iot-miniapp](../iot-miniapp) 进行远程监控与控制
