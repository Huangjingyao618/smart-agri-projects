# 🛒 农业电商扫码点餐小程序

> 微信小程序原生开发 · 菜品浏览 · 购物车 · 订单管理 · 扫码点餐

---

## 📋 项目简介

面向农业电商场景的扫码点餐微信小程序。用户通过扫描餐桌二维码进入点餐页面，浏览菜品、加入购物车、提交订单，实现数字化扫码点餐体验。

---

## 📁 项目结构

```
agri-food-miniapp/
├── app.js                    # 全局入口
├── app.json                  # 小程序配置
│                             #   - 单页应用: pages/index/index
│                             #   - 导航栏: "扫描点餐"
│                             #   - 组件框架: glass-easel
├── app.wxss                  # 全局样式
├── pages/
│   └── index/                # 点餐主页
│       ├── index.js          # 页面逻辑: 菜单数据 + 购物车管理
│       ├── index.wxml        # 页面模板: 菜品列表 + 购物车 + 下单
│       └── index.wxss        # 页面样式
├── images/                   # 菜品图片资源
├── project.config.json       # 项目编译配置
└── sitemap.json              # 站点地图
```

## ✅ 功能

- ✅ 菜品列表浏览 (图片 + 名称 + 价格)
- ✅ 购物车管理 (添加/删除/数量修改)
- ✅ 订单提交
- ✅ 扫码点餐入口 (扫描餐桌二维码直达)

---

## 🚀 使用说明

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入 `agri-food-miniapp/` 目录
3. 编译预览
